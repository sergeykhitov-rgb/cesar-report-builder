# CESAR SATELLITE — Конструктор отчётов

Онлайн-платформа: оператор заполняет отчёт (данные объекта, сводка, фото с датой и
адресом), нажимает **«Сгенерировать отчёт»** и получает **общедоступную ссылку**
`/(r)/<id>`, которая открывается и с компьютера, и с телефона.

Стиль, логотип и фирменные цвета взяты из коммерческого предложения CESAR SATELLITE (Figma).

## Запуск

```bash
node server.js
```

- Локально: <http://localhost:4600>
- С телефона в той же Wi-Fi: адрес `http://<ip-компьютера>:4600` (сервер печатает его при старте)

Никаких зависимостей ставить не нужно — только Node.js.

## Как устроено

| Файл | Назначение |
|------|-----------|
| `server.js` | Node-сервер: статика, API, публичные страницы. Отчёты — в `data/reports/<id>.json` |
| `public/index.html` + `editor.js` + `editor.css` | Редактор: форма + живой предпросмотр + генерация ссылки |
| `public/report.html` | Публичная страница отчёта (`/r/<id>`) |
| `public/report-render.js` | Общий рендер отчёта (одинаков в предпросмотре и на публичной странице) |
| `public/theme.css` | Фирменная тема CESAR SATELLITE |
| `public/logo.svg`, `logo-mark.svg` | Логотип |

## Фирменные токены

- Красный `#E30613` (→ `#BE0410`), жёлтый `#FFCC00`
- Текст `#141519`, серый `#6B7280`, линии `#EBEDF1`, фон `#EEF1F5`
- Шрифт **Onest**, скругление 22px

## Данные

- Фото хранятся прямо в JSON отчёта (base64), картинки ужимаются в браузере перед отправкой.
- Каждый отчёт — отдельный файл в `data/reports/`. Чтобы удалить отчёт — удалите файл.

## Публикация в интернет (по желанию)

Сейчас ссылка работает локально/в сети. Для настоящего публичного доступа сервер
разворачивается на любом Node-хостинге (Render, Railway, VPS). Для serverless-хостингов
(Vercel) хранилище нужно заменить на постоянное (S3/БД), т.к. их файловая система временная.
